PRINTTECH LED UV SYSTEM

การพิมพ์ที่แห้งด้วยระบบ LED UV สามารถประหยัดพลังงานไฟฟ้าได้มากกว่าระบบ Conventional UV (หลอด Mercury) ที่ใช้กันโดยทั่วไปกว่า 3 เท่า

ขณะพิมพ์งานยังไม่เกิดความร้อนที่ทำให้วัสดุพิมพ์เสียหาย และยังไม่สร้าง Ozone ปลอดภัยต่อช่างพิมพ์ และเป็นมิตรต่อสิ่งแวดล้อม

งานพิมพ์ที่ไม่มีติดขัด

เทคนิคการพิมพ์ที่ใช้ LED UV ทำให้งานพิมพ์แห้งทันที สามารถลดเวลาการผลิตงานในขั้นตอนการพิมพ์ลงได้ไม่ต่ำกว่า 30% เทียบกับการพิมพ์หมึก Oil Based เพราะไม่ต้องรอแห้งกลับหลัง และลดมูลค่าความเสียหายจากปัญหางานพิมพ์เลอะหลัง หรือพิมพ์ถอน

นอกจากนั้นยังไม่ใช้แป้งพ่นในการพิมพ์ จึงไม่มีฝุ่นแป้งติดผิวงานพิมพ์ เหมาะกับงานพิมพ์คุณภาพสูง อาทิ งานแคตาล็อกระดับพรีเมี่ยม (รถยนต์ จิวเวอรี่ คอสเมติก)

  • 3×ประหยัดไฟกว่าหลอด Mercury
  • 30%+ลดเวลาขั้นตอนการพิมพ์
  • 385 / 395 nmเลือกความยาวคลื่นได้
  • 30–110 mmระยะจากชุดหลอดถึง Gripper

System Configurations

รูปภาพ

เครื่องพิมพ์ Sheetfed Offset หรือ Narrow Web

สามารถติดตั้งกับเครื่องพิมพ์เดิมที่ใช้งานอยู่ (โดยปัจจุบันใช้หมึก Oil-Based และต้องการเป็นหมึกที่แห้งด้วยแสง UV) หรือ เครื่องพิมพ์ใหม่

รูปภาพ

หน้าจอควบคุมแบบสัมผัส

มีบริเวณ 2 จุด ที่ไดรฟ์เวอร์ และบริเวณโต๊ะควบคุมสี โปรแกรมรองรับภาษาไทย และสามารถกำหนดค่าการเปิด LED UV Lamp ตามความต้องการของช่างพิมพ์ได้อย่างสะดวก

รูปภาพ

ระบบ Optic ของชุดหลอด LED

ถูกออกแบบมาให้ติดตั้งโดยมีระยะห่างระหว่างชุดหลอด LED UV ถึง Gripper (กริ๊ปเปอร์) ได้ตั้งแต่ 30 - 110 มม. โดยยังคงความเข้มข้นแสงสูงทำให้งานพิมพ์แห้งสมบูรณ์ แม้พิมพ์ที่ความเร็วสูงสุดของเครื่องพิมพ์

รูปภาพ

ค่าความเข้มแสงสูง

สามารถเลือกใช้ได้ใน 2 ช่วงความยาวคลื่นแสงคือ 385nm และ 395nm นอกจากนั้นยังสามารถปรับแต่งระบบสำหรับโรงพิมพ์ตามประเภทงานพิมพ์แบบต่างๆ เช่น หนังสือ บรรจุภัณฑ์กระดาษ พลาสติก หรือ โลหะ

รูปภาพ

โครงสร้างชุดหลอด LED

เป็นโลหะผสม มีขนาดเล็ก สามารถติดตั้งได้ในเครื่องพิมพ์ Sheetfed Offset และเครื่องพิมพ์ป้อนม้วน Narrow Web ทุกยี่ห้อ ทั้งจากญี่ปุ่น หรือยุโรป

รูปภาพ

ระบบหล่อเย็น

ใช้น้ำเป็นตัวกลางระบบหล่อเย็น ช่วยให้การแผ่กระจายแสง UV มีความสม่ำเสมอ
